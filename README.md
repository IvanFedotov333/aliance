# Aliance — Медицинский лендинг (учебный проект)

Адаптивная, семантически чистая вёрстка по макету Figma. 
Современный стек, модальные окна и формы обратной связи.

## 🛠️ Ключевые особенности
- **Адаптивность:** Корректное отображение на устройствах от 320px до 1920px
- **Методология БЭМ:** Читаемый, масштабируемый код
- **Модальные окна:** Реализованы через JavaScript, закрываются по крестику, оверлею и Escape
- **Валидный код:** Проверен на W3C, без ошибок
- **Кроссбраузерность:** Последние версии Chrome, Firefox, Safari, Opera

## ⚙️ Используемые технологии
